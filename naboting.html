Naboting

En låneplatform for beboere i samme boligfællesskab. Fuldt udviklet med MySQL database, Express.js backend og Vue.js frontend.

Projektbeskrivelse

Naboting er en web-applikation, der gør det muligt for beboere i samme boligfællesskab at låne genstande fra hinanden. Systemet håndterer brugeradministration, oprettelse og administration af genstande, billeder, tilbehør samt låneanmodninger.

Projektet blev udviklet som eksamensopgave med fokus på databasedesign, backend-logik og frontend-brugeroplevelse.

Teknologi & Stack

Database

MySQL med normalisering til 3NF, ER-diagrammer, stored procedures

Backend

Express.js, Node.js, REST API, CRUD-operations

Frontend

Vue.js, JavaScript, HTML5, CSS3, responsive design

Andre Tools

Git, ER-diagram tools, MySQL Workbench, Postman

Kernefeatures

  • Brugeradministration: Registrering, login, brugerprofile med lokation
  • Genstandsadministration: Opret, rediger og slet genstande med kategori, tilstand og mængde
  • Billedhåndtering: Upload af billeder til genstande med primært billede-system
  • Tilbehør: Tilknyt tilbehør til genstande (f.eks. kabler til elektronik)
  • Låneanmodninger: Beboere kan anmode om at låne genstande med start- og slutdatoer
  • Lånestatus: Track låne-status (pending, approved, rejected, returned)
  • Kommunikation: Beskedetype mellem ejer og låner i låneformularen

Udviklingsprocesen

1. Database Design

Startede med at definere entiteter (brugere, genstande, billeder, tilbehør, lån) og deres relationer. Normaliserede til 3. normalform (3NF) for at minimere redundans og sikre dataintegritet:

  • 1NF: Atomare værdier - billeder og tilbehør i separate tabeller
  • 2NF: Fuld afhængighed af primærnøglen
  • 3NF: Ingen afhængighed mellem ikke-nøglefelter

2. Backend Implementation

Implementerede REST API med Express.js og mysql2:

  • CRUD-operations: POST, GET, PUT, DELETE endpoints
  • Stored Procedures: CreateLoan procedure med validering
  • Transaktioner: Sikring af data-konsistens ved komplekse operationer
  • Error Handling: Håndtering af fejl fra database og validering

3. Frontend Development

Bygget med Vue.js for interaktiv brugeroplevelse:

  • Komponenter for genstandsliste, brugerprofile og låneformularer
  • Form-validering og real-time feedback
  • API-integration med backend
  • Responsive design for mobil og desktop

Udfordringer & Løsninger

Trigger-begrænsning i MySQL 5.7

Problem: Ville implementere en trigger, der automatisk sikrer, at kun ét billede er "primært" ad gangen. Men MySQL tillader ikke at en trigger på en tabel ændrer data i samme tabel.

Løsning: Flyttede logikken til backend ved hjælp af transaktioner. Nu sættes alle eksisterende billeder til is_primary = 0, før det nye indsættes med is_primary = 1.

Database Validering

Problem: Skulle sikre, at en genstand ikke kan lånes hvis den ikke er tilgængelig.

Løsning: Implementerede validering i stored procedure CreateLoan, som tjekker status før lån oprettes.

Billedhåndtering

Problem: Balancere mellem at gemme billeder som filer eller URLs.

Løsning: Valgte at gemme som URLs/stier, hvilket gør databasen lettere og mere skalerbar.
